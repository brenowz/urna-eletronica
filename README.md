# 🗳️ Urna Cidadã: Simulação Educativa do Voto Eletrônico e Combate à Desinformação

> Projeto desenvolvido no âmbito da disciplina de Programação Orientada a Objetos (POO) e de Extensão Curricular da **Unijorge** (2026.2).

---

## 📌 Sobre o Projeto
O **Urna Cidadã** é um software educativo desenvolvido em **Java** (com interface gráfica em **Java Swing** e persistência de dados em nuvem via **Firebase Cloud Firestore**)[cite: 4, 7]. 

Mais do que apenas simular o ato de votar, o projeto tem um forte pilar de extensão comunitária voltado para escolas de Ensino Médio[cite: 5, 6]. O sistema engloba:
* **Simulador de Votação Oficial:** Reproduz a votação sequencial para dois cargos (um proporcional e um majoritário) com base na lógica da urna eletrônica brasileira[cite: 4, 7].
* **Módulo Informativo e Cidadão:** Informações e conteúdos didáticos sobre o funcionamento das eleições, as funções exercidas na política e a literacia eleitoral.
* **Combate à Desinformação:** Seção dedicada a conscientizar os jovens contra *fake news* e conteúdos manipulados por Inteligência Artificial (*deepfakes*) em períodos eleitorais[cite: 4, 5, 9].
